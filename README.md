# 💤 بوت الغياب AFK ・ Codeon

خلّ الكل يعرف إنك غايب ومن متى. مجاني 100% من متجر **Codeon** 🤍

## المميزات
- 💤 **غياب بسبب**: اكتب سببك: نايم، بالدوام، أصلي
- 🏷️ **[AFK] بالاسم**: يضيفها جنب اسمك ويرجّع اسمك بعدين
- 💬 **رد على المنشن**: يقول إنك غايب ومن متى بدون سبام
- 📨 **ملخص العودة**: مين منشنك وأنت غايب مع روابط الرسائل
- 💾 **حفظ أكثر أماناً**: كتابة ذرّية لملف البيانات لتقليل احتمال تلفه عند الإيقاف
- 🧹 **إدارة الذاكرة**: تنظيف بيانات كولداون الردود القديمة تلقائياً

## الأوامر
- `/afk` ・ حط نفسك غايب مع السبب
- `/afklist` ・ مين غايب الحين
- `/afkadmin remove` ・ شيل الغياب عن عضو
- `/afkadmin nickname` ・ تشغيل أو إيقاف [AFK] بالاسم
- `/afkadmin ignore` ・ روم ما يشيل فيه الغياب

## التشغيل
1. سوّ بوت من https://discord.com/developers/applications ← New Application ← Bot ← Reset Token وانسخ التوكن
2. انسخ ملف `.env.example` وسمّه `.env` وحط التوكن: `TOKEN=التوكن`
3. ما يحتاج تفعّل أي Intents إضافية ✅
4. ادعُ البوت: OAuth2 ← URL Generator ← اختر `bot` و `applications.commands` ← الصلاحيات `Administrator`
5. لازم Node.js 18 أو أحدث، بعدها:
```
npm install
npm start
```
6. الأوامر تطلع خلال دقيقة. لو ما طلعت، سكّر ديسكورد وافتحه.

> 💡 رتبة البوت لازم تكون **فوق** الرتب اللي يتحكم فيها.
