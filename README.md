# 💤 CASS AFK — بوت الغياب ولوحة التحكم

بوت Discord لإدارة حالة الغياب، مع لوحة تحكم ويب عربية.

## المميزات
- `/afk` لتفعيل الغياب مع سبب اختياري.
- يرد على منشن العضو الغائب ويسجل المنشنات.
- ملخص عند العودة مع روابط الرسائل.
- إضافة [AFK] للاسم وإرجاع اللقب الأصلي.
- `/afklist` لعرض الغائبين.
- `/afkadmin` لإدارة إعدادات الغياب.
- لوحة ويب عربية تعرض حالة البوت والسيرفرات وحالات AFK.
- تسجيل دخول Discord OAuth2، مع السماح فقط لمن يملك صلاحية إدارة السيرفر، والبوت موجود فيه.

## تشغيل البوت واللوحة

يتطلب Node.js 18 أو أحدث.

1. أنشئ تطبيقاً وبوتاً من https://discord.com/developers/applications
2. انسخ `.env.example` إلى `.env`.
3. املأ `TOKEN` بتوكن البوت.
4. ثبّت الحزم وشغّل:
   ```bash
   npm install
   npm start
   ```
5. لوحة التحكم تعمل على المنفذ المحدد في `PORT` (الافتراضي 3000).

## إعداد تسجيل دخول Discord للوحة

من Developer Portal ← OAuth2 أضف Redirect URL مطابقاً تماماً لقيمة `REDIRECT_URI`، مثلاً:

`https://YOUR-DOMAIN/auth/callback`

ثم عيّن متغيرات البيئة التالية في منصة الاستضافة، وليس في GitHub:

- `CLIENT_ID`: Application ID.
- `CLIENT_SECRET`: OAuth2 Client Secret.
- `REDIRECT_URI`: رابط الرجوع المسجل في Discord.
- `PUBLIC_URL`: عنوان اللوحة الأساسي دون مسار.
- `SESSION_SECRET`: قيمة عشوائية طويلة وسرية.
- `TOKEN`: توكن البوت.
- `PORT`: المنفذ الذي توفره منصة الاستضافة.

لا ترفع ملف `.env` ولا تشارك أي سر أو توكن. ملف `.env.example` يحتوي أسماء المتغيرات فقط.

## النشر

يجب نشر البوت واللوحة كخدمة Node.js واحدة تعمل بعملية واحدة، وتوجيه الزيارات إلى المنفذ `PORT`. تأكد من تفعيل HTTPS قبل استخدام OAuth في الإنتاج.

**ملاحظة تخزين:** قاعدة البيانات الحالية ملف JSON محلي. بعض منصات الاستضافة تمسح الملفات عند إعادة التشغيل أو إعادة النشر؛ استخدم قرصاً دائماً (Persistent Disk) أو قاعدة بيانات دائمة حتى لا تفقد حالات الغياب. جلسات تسجيل الدخول الحالية محفوظة في ذاكرة العملية، لذلك قد يحتاج المستخدم إلى تسجيل الدخول مجدداً بعد إعادة تشغيل الخدمة.

## الأوامر
- `/afk [reason]`
- `/afklist`
- `/afkadmin remove`
- `/afkadmin nickname`
- `/afkadmin ignore`

لا يحتاج البوت إلى Privileged Gateway Intents إضافية. ضع رتبة البوت فوق الرتب التي تريد تعديل أسمائها.
